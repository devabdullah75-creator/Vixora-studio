# ABX MOTION — Asset Replacement Directory

Place your custom project stills and cover images in this directory to automatically override procedural graphics. The illustrated portrait asset is used in the navigation avatar, biography card, and favicon:

- `abdullah-avatar.png` — Abdullah's illustrated avatar and favicon image (square PNG).
- `project-01.jpg` — Visual Identity in Motion cover thumbnail (16:9 cinematic or 4:3).
- `project-02.jpg` — Abstract Dimensions cover thumbnail.
- `project-03.jpg` — Product Motion Study cover thumbnail.
- `project-04.jpg` — Typography Experiments cover thumbnail.
- `project-05.jpg` — Digital Campaign cover thumbnail.
- `project-06.jpg` — Motion Exploration cover thumbnail.

All image and video paths are centralized in:
- `src/config/site.ts` (Personal bio, contact, portrait image path)
- `src/data/projects.ts` (Project media paths, metadata, descriptions)
